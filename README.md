# ticketco-stats

### JEG HAR IKKE SKREVET DETTE SCRIPTET. JEG ER IKKE ANSVARLIG HVIS DETTE SCRIPTET FUCKER OPP ET ELLER ANNET FOR DEG.

Hvordan bruke scriptet:
1. Åpne et arrangement i Ticketco (URLen avsluttes som oftest med `/events/{event_id}/seating_arrangement`)
2. Åpne konsollen (F12)
3. Kjør først kommandoen "allow pasting"
4. Lim scriptet inn i konsollen
5. La scriptet jobbe litt
6. Voilà
